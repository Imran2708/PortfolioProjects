# Credit Card Customer Churn - Portfolio Project

## 📌 Project Overview
**Harbor Trust Bank** observed a decline in its credit card users, leading to revenue loss. This project analyzes customer behavior and financial metrics to understand **why customers leave** and suggests actionable steps for retention.

## 📁 Project Structure
```
credit-card-customer-churn/
│- Credit Card Customer Churn Analysis Report (Detailed analysis & findings)
│- BankChurners.csv (Dataset used for analysis)
│- Credit Card Customer Churn (Project documentation)
│- main.py (Python script for data analysis)
│- README.md (Project description, approach, and key insights)
```

## 🔍 Business Problem
Harbor Trust Bank earns revenue through various credit card fees, but **customer churn** is reducing profitability. Understanding **which customers are leaving and why** will help the bank improve retention strategies.

## 🔑 How I Solved It
1. **Data Quality Assessment:** Checked for missing values, duplicates, and inconsistencies in the dataset.
2. **Data Cleaning:** Ensured consistency by handling "Unknown" values and standardizing formats.
3. **Outlier Detection & Handling:** Identified and addressed extreme values in financial metrics like Credit Limit and Transaction Amount.
4. **Exploratory Data Analysis (EDA):** Analyzed distributions, trends, and correlations to uncover key churn drivers.
5. **Insights & Business Recommendations:** Suggested retention strategies based on findings from EDA.

## 🛠️ Skills & Tools Used
- **Python (pandas, numpy, matplotlib, seaborn)** - Data analysis, data quality assessment, cleaning, outlier detection, and visualization
- **Exploratory Data Analysis (EDA)** - Identifying trends, patterns, and key insights

## 🚀 Key Takeaways
✔ Identified **high-risk customers** by analyzing spending behavior and inactivity trends.
✔ Recommended **targeted retention strategies** to reduce churn.
✔ Applied **real-world data analytics techniques** to solve a banking problem.
